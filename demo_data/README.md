# Demo Data — Sovereign AI Workbench

> **PUBLIC DEMONSTRATION DATA**
> 
> The files in this directory are synthetic demonstration data created
> specifically for the Sovereign AI Workbench hackathon prototype.
> 
> They do NOT contain real confidential, proprietary, or classified information.
> They are safe to share, commit, and use in presentations.

## Contents

1. **equipment_readings.csv** — Synthetic equipment sensor data (temperature, pressure, vibration, flow rate) for demonstration of the Data Analysis Agent.

2. **sample_inspection_report.txt** — A synthetic equipment inspection report for demonstration of the OCR → RAG → Report pipeline.

3. **sample_sop.txt** — A synthetic Standard Operating Procedure document for demonstrating RAG knowledge base retrieval.
